# SIMBOIS

**Sistem Informasi Monitoring dan Bimbingan Online Integrasi Sosial**
Balai Pemasyarakatan (Bapas) Kelas I Malang.

Platform wajib lapor bulanan untuk Klien Pemasyarakatan, manajemen Pegawai Pembimbing Kemasyarakatan (PK), serta monitoring kepatuhan secara real-time.

## Tech Stack

- Vite + React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion
- Leaflet (peta lokasi wajib lapor)

## Menjalankan Secara Lokal

Prasyarat: Node.js & npm.

```sh
npm install
npm run dev
```

Aplikasi berjalan di `http://localhost:8080`.

## Build Produksi

```sh
npm run build
npm run preview
```
